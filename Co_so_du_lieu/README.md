# Database Design

## Tài liệu thiết kế cơ sở dữ liệu

Tài liệu bao gồm:
- Sơ đồ thực thể và quan hệ (ERD) giữa users và tasks.
- Mô tả cấu trúc bảng, kiểu dữ liệu và ràng buộc.
- Thiết kế khóa chính, khóa ngoại và index.
- Đối chiếu cấu trúc database với đặc tả API.

**Google Docs:** [Xem tài liệu thiết kế cơ sở dữ liệu](https://byvn.net/BtGD)
